# Ubuntu Bootstrap 

A simple 'one and done' shell script to install bens personal developemt kit (on a ubuntu Windows Subsystem Linux setup)

## Tooling / Languages included

* `pyenv` for installing various versions of `python`
  * The script will also install the `latest` python using it
* `rust` toolchain 
* `nvm` for managing `node` installations
* `zsh` and `oh-my-zsh` 

## IDE / Editor

* `zed` code editor

## Running 

```shell
chmod 755 ./bootstrap.sh
./bootstrap.sh
```
